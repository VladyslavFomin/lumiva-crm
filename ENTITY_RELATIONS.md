# Связи между сущностями CRM

## Общая структура связей

```
Company (Компания)
  ├── OneToMany → Contact (Контакты компании)
  ├── OneToMany → Lead (Лиды компании)
  └── OneToMany → Project (Проекты компании)

Contact (Контакт)
  ├── ManyToOne → Company (Компания контакта)
  ├── OneToMany → Lead (Лиды контакта)
  └── OneToMany → Project (Проекты контакта)

Lead (Лид)
  ├── ManyToOne → Company (Компания лида) [опционально]
  ├── ManyToOne → Contact (Контакт лида) [опционально]
  └── OneToMany → Project (Проекты лида)

Project (Проект)
  ├── ManyToOne → Lead (Лид проекта) [опционально]
  ├── ManyToOne → Company (Компания проекта) [опционально]
  └── ManyToOne → Contact (Контакт проекта) [опционально]
```

## Детальное описание связей

### 1. Company (Компания)

**Связи:**
- `contacts: Contact[]` - Контакты, принадлежащие компании
- `leads: Lead[]` - Лиды, связанные с компанией
- `projects: Project[]` - Проекты, связанные с компанией
- `tasks: CompanyTask[]` - Задачи компании

**Поля:**
- `id: string` - UUID компании

### 2. Contact (Контакт)

**Связи:**
- `company: Company | null` - Компания, к которой принадлежит контакт
- `leads: Lead[]` - Лиды, связанные с контактом
- `projects: Project[]` - Проекты, связанные с контактом

**Поля:**
- `id: string` - UUID контакта
- `companyId: string | null` - ID компании (FK)

### 3. Lead (Лид)

**Связи:**
- `company: Company | null` - Компания лида
- `contact: Contact | null` - Контакт лида
- `projects: Project[]` - Проекты, созданные из лида

**Поля:**
- `id: string` - UUID лида
- `companyId: string | null` - ID компании (FK)
- `contactId: string | null` - ID контакта (FK)

**Логика:**
- Лид может быть связан с компанией и/или контактом
- Лид является "сборщиком" данных - из него можно создать компанию и контакт

### 4. Project (Проект)

**Связи:**
- `lead: Lead | null` - Лид, из которого создан проект
- `company: Company | null` - Компания проекта
- `contact: Contact | null` - Контакт проекта

**Поля:**
- `id: string` - UUID проекта
- `leadId: string | null` - ID лида (FK)
- `companyId: string | null` - ID компании (FK)
- `contactId: string | null` - ID контакта (FK)

**Логика синхронизации:**
- При создании проекта с `leadId`, если не указаны `companyId`/`contactId`, они автоматически берутся из лида
- При обновлении `leadId` проекта, если не указаны `companyId`/`contactId`, они синхронизируются из лида

## Правила целостности данных

### 1. Иерархия: Company → Contact
- Контакт всегда принадлежит одной компании (или ни одной)
- Компания может иметь множество контактов

### 2. Лид как сборщик
- Лид может быть связан с компанией и/или контактом
- Из лида можно создать компанию и контакт
- При создании компании из лида, лид автоматически привязывается к компании

### 3. Проект наследует связи
- Проект может быть связан с лидом, компанией и контактом
- При создании проекта из лида, автоматически наследуются связи с компанией и контактом
- Это обеспечивает консистентность данных

## Операции каскадного удаления

- **Company → Contact**: `onDelete: 'SET NULL'` - при удалении компании, контакты остаются, но теряют связь
- **Company → Lead**: `onDelete: 'SET NULL'` - при удалении компании, лиды остаются, но теряют связь
- **Company → Project**: `onDelete: 'SET NULL'` - при удалении компании, проекты остаются, но теряют связь
- **Contact → Lead**: `onDelete: 'SET NULL'` - при удалении контакта, лиды остаются, но теряют связь
- **Contact → Project**: `onDelete: 'SET NULL'` - при удалении контакта, проекты остаются, но теряют связь
- **Lead → Project**: `cascade: false` - при удалении лида, проекты остаются, но теряют связь

## Рекомендации по использованию

1. **Создание лида:**
   - Можно указать `companyId` и/или `contactId`
   - Если не указаны, можно создать компанию/контакт из лида

2. **Создание проекта:**
   - Рекомендуется указать `leadId`
   - `companyId` и `contactId` автоматически синхронизируются из лида
   - Можно переопределить вручную

3. **Обновление связей:**
   - При изменении `companyId`/`contactId` в лиде, проекты НЕ обновляются автоматически
   - При изменении `leadId` в проекте, `companyId`/`contactId` синхронизируются из лида

## Потенциальные проблемы и решения

### Проблема: Рассинхрон данных
**Симптом:** Проект связан с лидом, но у лида изменилась компания, а у проекта осталась старая.

**Решение:** 
- При обновлении проекта с `leadId`, автоматически синхронизируются `companyId`/`contactId`
- Рекомендуется обновлять проекты при изменении связей лида (можно добавить автоматизацию)

### Проблема: Дублирование данных
**Симптом:** В лиде и проекте хранятся одни и те же данные о компании/контакте.

**Решение:**
- Используются только FK (companyId, contactId), данные не дублируются
- Названия компаний/контактов хранятся только в соответствующих таблицах
