# Lumiva CRM

## Дизайн

Любые изменения UI внутренних страниц CRM (новые страницы, модалки, блоки, редизайн по макету) делаются
по `md/design-system.md`: шрифты только через токены `--ff-heading` / `--ff-text` / `--ff-mono-ui`,
шапка страницы — `PageHero` (или `.xx-hero` по образцу `bk-hero`), кнопки `btn-*` в обычном регистре,
монохромный акцент `#222`, страницы во всю ширину. Перед сдачей пройдите чек-лист из §12.

Если вводите новый элемент или меняете правило — сначала обновите `md/design-system.md`.
Макеты Claude Design переносятся в эту систему: структуру и идеи берём из макета, шрифты/цвета/кнопки — отсюда.
