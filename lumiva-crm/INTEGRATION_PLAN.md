# План интеграции Компаний и Контактов с Лидами и Проектами

## Текущая ситуация

### Существующие сущности:
- **Лиды (Leads)** - основная сущность, связана с Contact (contactId)
- **Проекты (Projects)** - связаны с Lead (leadId)
- **Контакты (Contacts)** - имеют companyId, но связь не активна
- **Компании (Companies)** - изолированы, нет связей

### Проблемы:
1. ❌ Нет полной интеграции между сущностями
2. ❌ Разный дизайн страниц (старый vs новый темный стиль)
3. ❌ Нет аналитики по компаниям/контактам
4. ❌ Нет связи с метриками и проектами

---

## Архитектура интеграции

### 1. Связи между сущностями

```
Company (Компания)
  ├── OneToMany → Contacts (контакты компании)
  ├── OneToMany → Leads (лиды от компании)
  └── OneToMany → Projects (проекты компании)

Contact (Контакт)
  ├── ManyToOne → Company (компания контакта)
  ├── OneToMany → Leads (лиды контакта)
  └── OneToMany → Projects (проекты контакта)

Lead (Лид)
  ├── ManyToOne → Contact (контакт лида)
  ├── ManyToOne → Company (компания лида, через contact.company)
  └── OneToMany → Projects (проекты лида)

Project (Проект)
  ├── ManyToOne → Lead (лид проекта)
  ├── ManyToOne → Contact (контакт проекта, через lead.contact)
  └── ManyToOne → Company (компания проекта, через lead.contact.company)
```

### 2. Изменения в Entity

#### Lead Entity:
- ✅ Уже есть `contactId` - связь с Contact
- ➕ Добавить `companyId` (опционально, для прямой связи)
- ➕ Добавить вычисляемое поле `company` через `contact.company`

#### Contact Entity:
- ✅ Уже есть `companyId`
- ➕ Активировать связь `@ManyToOne(() => Company)`
- ➕ Добавить `@OneToMany(() => Lead)` для связи с лидами
- ➕ Добавить `@OneToMany(() => Project)` для связи с проектами

#### Company Entity:
- ➕ Добавить `@OneToMany(() => Contact)` - контакты компании
- ➕ Добавить `@OneToMany(() => Lead)` - лиды компании
- ➕ Добавить `@OneToMany(() => Project)` - проекты компании

#### Project Entity:
- ✅ Уже есть `leadId`
- ➕ Добавить `contactId` (опционально, через lead.contact)
- ➕ Добавить `companyId` (опционально, через lead.contact.company)

## Аналитика

### Метрики по компаниям:
1. **Количество лидов:**
   - Всего лидов
   - По статусам (новый, в работе, закрыт)
   - Конверсия в проекты

2. **Количество проектов:**
   - Всего проектов
   - По статусам (новый, в работе, закрыт)
   - Общая сумма проектов

3. **Финансовые метрики:**
   - Общая сумма всех проектов
   - Средняя сумма проекта
   - Сумма закрытых проектов

4. **Временные метрики:**
   - Среднее время от лида до проекта
   - Среднее время выполнения проекта
   - Последняя активность

### Метрики по контактам:
1. **Количество лидов** (аналогично компаниям)
2. **Количество проектов** (аналогично компаниям)
3. **Финансовые метрики** (аналогично компаниям)
4. **Временные метрики** (аналогично компаниям)

### API для аналитики:
```
GET /v1/companies/:id/analytics
GET /v1/contacts/:id/analytics
GET /v1/companies/analytics (общая статистика)
GET /v1/contacts/analytics (общая статистика)
```

## Примеры использования

### Сценарий 1: Новый лид от компании
1. Создается лид
2. Выбирается компания (или создается новая)
3. Выбирается контакт компании (или создается новый)
4. Лид автоматически связывается с компанией и контактом

1. Открывается страница компании
2. Видны все контакты компании
3. Видны все лиды компании
4. Видны все проекты компании
5. Видна аналитика: конверсия, суммы, активность

### Сценарий 3: Аналитика
1. Открывается страница "Аналитика компаний"
2. Видны метрики по всем компаниям:
   - Топ компаний по количеству проектов
   - Топ компаний по сумме проектов
   - Конверсия лидов в проекты
   - Среднее время цикла
