# Lumiva CRM — дизайн-система

Единый визуальный язык всех внутренних страниц CRM (всё, что рендерится внутри `MainLayout`).
Любая новая страница, модалка или блок делается по этому документу. Если нужен элемент, которого здесь нет, —
сначала добавьте его сюда, потом в код.

Публичный сайт (`pages/public`, `pages/landing`, `components/public`), публичные страницы клиентов
(`/m/:slug`, портал, e-sign для подписанта) и темы дашбордов Aura — **вне** этой системы.

Эталон для сверки: Бронирования (`pages/bookings/bookings-design.css`), Лиды, Компании, Товары.

---

## 1. Принципы

- **Монохром.** Акцент — тёмный `#222`, а не синий/фиолетовый. Цвет — только для статусов и данных (графики).
- **Тонкие линии вместо теней.** Карточки — белые с рамкой `#e7e7e7`; тени — только у всплывающих слоёв.
- **Во всю ширину.** Никаких `max-w-*` контейнеров на уровне страницы — блоки от края до края контентной области.
  Ограничивать ширину можно только у абзацев (подзаголовок ≤ 560px).
- **Узкие заголовки, ровный текст, моно-подписи.** Три гарнитуры, у каждой своя роль (см. §2).
- **Обычный регистр** у кнопок, вкладок и заголовков. КАПС — только у мелких моно-подписей.

## 2. Шрифты

Токены объявлены в `frontend/src/index.css` (`:root`). Прописывать гарнитуры руками нельзя — только через токены.

| Токен | Значение | Для чего |
|---|---|---|
| `--ff-heading` (= `--ff-display`) | `'Barlow Condensed', 'Roboto Condensed', …` | заголовки h1–h3, названия карточек/сущностей, крупные цифры KPI |
| `--ff-text` | `'Inter', …` | весь основной текст, кнопки, поля, вкладки, таблицы |
| `--ff-mono-ui` (в модулях `--ff-mono`) | `'JetBrains Mono', …` | надзаголовки (kicker), подписи KPI, шапки таблиц, ID, коды |

- У Barlow Condensed **нет кириллицы** — русские буквы берёт Roboto Condensed. Не убирайте его из стека.
- Заголовки: `font-weight: 600`, `letter-spacing: 0` (отрицательный трекинг на узком шрифте «слипается»).
- Внутри `.lv-crm` все `h1–h3` автоматически получают `--ff-heading`; в Tailwind-разметке можно использовать класс `cd-display`.
- Основной текст CRM — Inter (правило `body:has(.lv-crm)`), Poppins остаётся только у публичного сайта.

## 4. Шапка страницы

Каждая страница начинается одинаково:

```
● KICKER · РАЗДЕЛ                                   [Вторичная] [+ Основная]
Заголовок страницы (34px)
Подзаголовок 13px #888, до 560px
──────────────────────────────────────────────────────────────── (1px #e7e7e7)
```

- Tailwind-страницы: компонент `PageHero` из `components/ui` (`kicker`, `title`, `subtitle`, `actions`).
- Модули со своим CSS: `.xx-hero` по образцу `.bk-hero` (flex, `align-items: flex-end`, `padding: 10px 0 18px`,
  `border-bottom: 1px solid var(--line-2)`).
- Старые классы `.page-header / .page-title / .page-subtitle` уже приведены к тем же метрикам — допустимы.
- Не заворачивайте шапку в белую карточку.
- Под шапкой — вкладки раздела (если есть), затем KPI-полоса, затем контент.

## 5. Кнопки

| Тип | Вид | Класс |
|---|---|---|
| Основная | фон `#222`, белый текст, 12px 600, радиус 9–12px, паддинг 9×14 | `btn-primary` (`-sm`, `-lg`) |
| Вторичная | белая, рамка `#e7e7e7`, текст `#222`, 12–12.5px 500; hover — рамка `#222` | `btn-secondary` (`-sm`) |
| Тихая | без рамки и фона, текст `#555`, hover — фон `#f1f3f8` | `btn-ghost` |
| Опасная | белая, текст `#9a1f31`, рамка `#f0c8cf` | `btn-danger` |
| Иконка | 28–32px, без рамки | `btn-icon`, `btn-icon-danger` |

- Текст — **обычный регистр** («+ Новая бронь», а не «+ НОВАЯ БРОНЬ»).
- На странице одна основная кнопка — справа в шапке. Остальные действия — вторичные.
- Иконка слева 14px, `gap: 6–7px`. Плюс в тексте («+ Новый …») — допустим.
- Нажатие: `active:scale(.97)` (уже в классах).
- Загрузка файла — не нативный `<input type="file">`, а скрытый input + `btn-secondary` «Выбрать файл» + имя файла,
  или dropzone «Перетащите файл сюда или нажмите, чтобы выбрать».

## 6. Карточки, KPI, таблицы

**Карточка:** `background: #fff; border: 1px solid #e7e7e7; border-radius: 12px` (допустимо 10–14px).
Не используйте `rounded-3xl`, тяжёлые тени и цветные рамки. Заголовок карточки — h3 15–17px + подпись 11–12px `#888`.

**KPI-полоса:** одна общая рамка, ячейки разделены 1px линиями (не отдельные плавающие карточки):
подпись (mono 10px uppercase `#888`) → цифра (`--ff-heading` 26–28px) → пояснение/дельта (mono 10.5px).
Эталон: `.bk-kpi-grid / .bk-kpi`.

**Таблица:** обёртка с рамкой и радиусом 12px; шапка — `#fafafa`, mono 9.5px uppercase `#888`;
ячейки 11×14px, 12.5px, линии `#f0f0f0`; hover строки `#fafafa`; ID и коды — mono 11px `#888`.

**Пустое состояние:** по центру блока: (иконка/Lottie) → заголовок 14–16px 600 → пояснение 12–13px `#888` →
одна кнопка действия. Без восклицательных знаков и шуток.

## 7. Вкладки, фильтры, чипы

- **Вкладки раздела:** текст 13px `#888`, активная — `#222`, 500, подчёркивание 1.5–2px `#222`; общая нижняя линия `#e7e7e7`.
  Без капса, без узкого шрифта, без пилюль. Счётчик — mono 10px рядом.
- **Фильтр-чипы:** пилюли `border-radius: 999px`, 11–12px; активный — фон `#222`, белый текст; неактивный — прозрачный, `#555`.
- **Сегментированный переключатель** (Таблица/Карточки, Мобильный/Десктоп): группа с рамкой, активный сегмент — `#222` или белый с тенью.
- **Период:** только общий `DateRangePicker` (`components/ui`).
- **Чекбокс:** единый глобальный стиль в `index.css` (блок CHECKBOX): 16×16, рамка `#c9c9cc`, радиус 5, отмеченный — `#222` с белой галочкой. Свой стиль чекбоксам не писать; нужен нативный — класс `lv-native`. Радио — `accent-color:#222`.
- **Одна дата:** `DateInput` (`components/ui`) вместо нативного `<input type="date">` — поповер в стиле `DateRangePicker`, можно печатать `дд.мм.гггг`; в тулбаре — `inline clearable={false}`.
- **Маленькие формы** (имя, период): модалка `bk-modal narrow`, не `window.prompt` и не абсолютный поповер у кнопки.
- **Select:** нативный `<select>` со стилем `base-select` / модульным полем — попап стилизуется глобально
  (см. блок MODERN SELECT в `index.css`; если у select свой шеврон — добавьте класс в whitelist там же).

## 8. Формы

- Подпись поля над полем: 11px `#888` (или mono 10px uppercase в плотных формах).
- Поле: высота ~36px, паддинг 9×10, рамка `#e7e7e7`, радиус 8px, 12.5–13px; focus — рамка `#222`.
- Обязательное поле — `*` после подписи. Ошибка — текст `#9a1f31` 11px под полем.
- Сохранение — основная кнопка справа внизу или в шапке; «Отмена» — вторичная/тихая рядом.

## 9. Модалки, дроуэры, уведомления

- Оверлей + панель: классы `lv-backdrop` + `lv-dialog` (модалка) или `lv-sheet-right` (дроуэр) из `motion.css`.
  Свои keyframes не писать.
- Панель: белая, радиус 14–16px, тень `0 24px 60px rgba(0,0,0,.18)`, заголовок h3 18–24px `--ff-heading`.
- Успешные действия — toast (`showAlert(…, { variant: 'success' })`), не модалка.
- Подтверждение удаления — модалка с `btn-danger`.

## 10. Движение

- Ощущение «живое, но не игривое»: короткие ease-out переходы (`--ease-out`, 150–250ms).
- Списки и таблицы — `lv-stagger`; появление блоков — `lv-reveal`; нажатия — `lv-press`.
- Не анимировать: цифры KPI, графики аналитики, навигацию.

## 11. Тексты и локализация

- Все строки — через i18n, сразу на трёх языках: ru / en / tr.
- Регистр предложения везде («Новая бронь»). КАПС пишется только CSS-ом у mono-подписей, не в переводах.
- Никаких выдуманных цифр и метрик в интерфейсе — только реальные данные или пустое состояние.

## 12. Чек-лист новой страницы

- [ ] Страница внутри `MainLayout`, без `max-w-*` обёртки.
- [ ] Шапка: kicker с точкой + h1 34px `--ff-heading` + подзаголовок + действия справа + линия снизу (`PageHero` или `.xx-hero`).
- [ ] Шрифты только через `--ff-heading` / `--ff-text` / `--ff-mono-ui`; нигде не прописаны `'Inter Tight'`, `'Poppins'`, `'Barlow'`.
- [ ] Одна основная кнопка, обычный регистр; остальные — вторичные.
- [ ] Карточки: белые, рамка `#e7e7e7`, радиус 12px; KPI — полоса с общими линиями; цвет только у статусов.
- [ ] Таблица: mono-шапка, линии `#f0f0f0`, hover `#fafafa`.
- [ ] Пустые, загрузочные и ошибочные состояния есть и оформлены по §6.
- [ ] Модалки/дроуэры на классах `lv-*`.
- [ ] Строки в ru/en/tr.
- [ ] `PageHelpButton` + тур (см. `md/lumiva_tours_plan.md`), если страница новая в меню.
- [ ] Скриншот страницы рядом с эталоном (Бронирования/Лиды) — шапка, кнопки, карточки выглядят как одна система.
